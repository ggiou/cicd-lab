# CICD-LAB

## Overview

Spring Boot 기반 애플리케이션을 대상으로 CI/CD Pipeline을 구축하는 프로젝트입니다.

GitHub, Jenkins, Docker, AWS 환경을 연결하여
Source Integration부터 Build, Test, Deployment까지
전체 CI/CD 흐름을 직접 구현합니다.


## Project Structure

This project is designed to build a production-like CI/CD pipeline.

The repository structure separates application,
CI/CD configuration, infrastructure, and documentation.

- app
    - Spring Boot Application

- docker
    - Containerization configuration

- jenkins
    - CI/CD Pipeline configuration

- nginx
    - Reverse Proxy configuration

- docs
    - Architecture, Troubleshooting and Decision Records
